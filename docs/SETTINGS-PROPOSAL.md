# 后台精简方案（待确认）

2026-10-20。依据当前源码及 Ego Lite 实际页面。账号规则属于已授权的 0.4.1 改动；下述导航重组与功能删除尚未实施。

目标：第一次打开知道该设置什么，日常改设置不需要理解 Jev、模型协议或判断原理。

## 推荐结构

- 日常入口六个：回复过滤、账号名单、待回复、搜索、书签、写作。
- 底部两个入口：模型设置、关于与帮助。
- 取消首页重复的功能目录。默认直接打开回复过滤。
- 页面采用一个标题、一句必要说明、一块主要操作区。开关、选择器和保存反馈统一对齐；列表搜索与操作固定在列表上方。

## 保留与合并

| 现状 | 建议 |
| --- | --- |
| 自动隐藏、独立高级规则 | 合并为回复过滤。首屏只留疑似 AI、引流、重复三项和敏感度；自定义阈值、附加规则、屏蔽词收进高级选项 |
| 例外名单、我的标注、常用 @ | 统一账号入口。先看到已折叠、始终显示；常用 @ 为次级管理入口；标记历史和导出放入记录抽屉 |
| 写作模型、回复判断模型 | 合为模型设置入口，内部保留写作、回复判断两种用途，凭据与协议仍独立 |
| 大量未配置服务卡片 | 已连接服务优先；其他服务从“添加服务”进入，完整模型管理继续保留 |
| 写长文与模型设置相邻的两个入口 | 写作直接进入草稿列表，编辑器内提供选模型与设置入口 |
| 传播表现 | 保留页面上的小火入口，开关放进浏览显示选项；默认只呈现速度、近期增量、互动 |

## 删除或降级

- 删除首页与侧栏重复的功能导航、重复状态文案、重复的阈值说明。
- 删除 AI / 真人标注排行榜及专用统计。账号已经按手动选择处理，排行榜不再帮助用户完成操作；原始标记记录保留。
- 已隐藏的看好追踪、兴趣评分作为退役候选：核对调用后删除无用入口、消息处理和计算，历史记录先提供导出，不直接删除用户数据。
- 社区共建从主流程移到高级选项，保持主动开启，保留退出与撤回入口。
- 判断公式、模板话术清单、样本选择方法放进帮助；主页面只留会影响使用选择的提示和错误解决办法。

## 文案示例

| 当前 | 调整后 |
| --- | --- |
| 回复区正在保持安静 | 回复过滤已开启 |
| 隐藏 AI 回复 | 折叠疑似 AI 回复 |
| 例外名单 | 账号名单 |
| 本机屏蔽 | 折叠此账号 |
| 我的标注 | 标记记录 |
| 已标记真人 | 始终显示 · 跳过判断 |
| 高于 50% 隐藏，恰好 50% 保留 | 标准；精确阈值只在高级选项展示 |

账号有三种可切换状态：自动检测、始终显示、默认折叠。自己的账号自动跳过；人工选择不会被后续模型结果覆盖。标为真人后仍保留中性账号菜单，可改标 AI 或恢复自动检测。模型单次预测不生成永久账号规则。

## 实施顺序与验收

1. 先改导航、重复入口、文案和布局，保留现有数据与配置；提供可操作预览。
2. 再清理确认退役的功能及后台路径，逐项验证没有后台计算或网络调用残留。

验收看：新用户能完成开启过滤、恢复一个账号、添加模型、打开草稿；普通设置页无需滚过长篇说明；桌面和 390px 下没有溢出；旧设置、草稿、书签、联系人与标记历史仍可访问。不要只以“少了多少按钮”作为成功标准。
