## X 专属适配

写作设置使用 X Helper 独立命名空间，不读取 Clipper 的真实密钥、文章或登录会话。Jev 仍使用 typed decisions，不能替换为聊天接口。含凭据请求验证目的域、拒绝重定向并省略 Cookie。

后台对写作消息与原 X 功能显式分流；长连接与图片任务只接受本扩展页面，拒绝 X 页面内容脚本、其他扩展与隐私窗口。offscreen 只使用 runtime API，由后台检查网络权限和读取配置。

Clipper 的网页剪藏、视频学习、字幕采集、播放器、下载器以及多平台发布不属于 X Helper 的写作工作流，未复制其产品入口。两款扩展的数据不会自动合并。

## 验收边界

自动测试、生产构建、本地浏览器夹具、真实模型文本、已安装扩展和平台草稿写入是独立证据。没有用模型列表、加载成功或合成图片代替真实生图。完整运行记录见 [QA](QA.md)，对外宣传图只使用实际生产界面并注明示例数据。
