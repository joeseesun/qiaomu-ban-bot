# 0.1.0 Preview 验证记录

更新：2026-10-18。此记录区分模型请求、代码测试、浏览器模拟页面和安装后的完整真实流程。

## 已验证

- `npm run package`：26 项自动测试通过，Chrome MV3 构建与 ZIP 打包成功。
- 核心策略：阈值/模式/名单优先级、异常响应不折叠、热帖数据门槛、缓存上下文与版本键。
- 后台引擎：同请求去重、并发与日预算、配置变更后拒绝旧结果、429 冷却、缓存/反馈、并行名单写入、密钥不随快照返回、换服务商清除旧密钥。
- 消息入口：设置页跳转 hash 后仍可保存；其他扩展、非 X 页面和子帧没有管理权限。
- DOM：主帖/回复/祖先/推荐区别、引文排除、本地化数字、原主帖被虚拟列表移除后保留上下文。
- 内容脚本：展开保留原节点；暂停恢复原文；复用节点不应用旧结果；手动保留优先于重复折叠；拉黑入口只到确认。
- 浏览器模拟页：疑似 AI 折叠、同文折叠、值得一读、热帖概率、展开；点击 X 屏蔽入口后模拟确认打开，实际屏蔽计数仍为 0。
- 浏览器设置页：浅/深色、400px 弹窗、360px 模型表单；无横向溢出，密码框聚焦无尺寸跳变。
- 实际 X 页面只读检查：成功提取一个主帖及 16 条回复，主帖与回复类型、作者和上下文关联正常。未对该页用户执行屏蔽或公开标记。

## 真实模型调用

经乔木 Magpie 使用生产代码中的 Jev 适配器调用，返回实际模型 `jev-1.13.0`。密钥仅从本机既有配置进入进程内存，没有写入源码、报告或安装包。

以下全部是构造文本，不是带标签的独立数据集，**不能据此推导准确率**。

| 样例 | AI 概率 | 低信息量 | 90% AI 模式结果 |
| --- | --- | --- | --- |
| 明确助手套话 | 92% | 88% | 折叠 |
| 具体人工风格纠错 | 14% | 14% | 保留 |
| 简短致谢 | 22% | 82% | 保留 |
| 引用 AI 表达讨论 | 37% | 34% | 保留 |
| 试图命令判断器输出固定答案 | 76% | 90% | 保留，并标低信息量 |
| 空泛夸赞 | 74% | 93% | 保留；低信息量模式会折叠 |

上述 6 次回复请求约 317–1,031ms/次；这是本次环境观测，不能承诺他人网络延迟。

热帖样例：构造一个发布约 1 小时、3,200 浏览、128 赞、32 回复、15 转帖的帖子，模型给出 24 小时达 10,000 浏览的概率 18%，请求约 898ms。这里只证明接口返回有效概率，不证明预测准确。
