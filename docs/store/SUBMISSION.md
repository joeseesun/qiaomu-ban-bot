## 可复用资料

- `listing-zh.txt`：中文商品介绍。
- `reviewer-notes.txt`：完整审核步骤；`reviewer-summary.txt`：后台 500 字限制内的摘要，均不含开发者凭据。
- `declarations.json`：单一用途、权限说明、披露类别与链接。
- `visuals.html`：截图排版源文件；`assets/` 为 0.1.10 生产 UI / 生产内容脚本夹具的截图，使用示例数据。
