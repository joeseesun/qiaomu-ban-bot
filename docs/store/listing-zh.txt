少刷一点噪音，多写一点自己的想法。

乔木 X 助手，为经常在 X 阅读、收藏与创作的人准备。把值得读的内容留下，把想回复的话写好，再把零散想法整理成文章。

读得清楚
按自己的规则折叠重复、引流或疑似 AI 回复，随时展开与纠正。保留你信任的作者，也可以只标记、不折叠。模型结果仅供参考，不能证明作者身份，不会自动拉黑账号。

收藏真正有用
随浏览保存已加载的书签，加备注和标签，按正文或作者搜索，一键导出 Markdown。书签、备注与原帖链接一起带走；不会自动扫描全部历史。

写作少切几个窗口
本机长文编辑器支持 Markdown、大纲、自动保存、回收站和含图片的导入导出。AI 可理解当前文章和选区，给出修改建议，由你接受后才改正文。

资料与配图，写的时候就能找
按需连接联网搜索和图片服务，在对话中查资料、查看来源、搜索图片或生成配图。独立图库保留结果，后台任务在关闭侧栏后仍可继续。

直接送到 X 草稿
点「发布到 X」，把文章和配图写入 X 原生文章草稿，不再多选一次平台。最终检查与发布由你完成，需要账号拥有 X Articles 权限。

互动有条理
把值得回复的帖子加入待回复，保存思路，再填入对应回复框。常用 @ 支持昵称、拼音、账号和备注搜索；高级搜索可保存关键词、作者、时间与互动条件。

按需配置
基础写作、书签、搜索条件和待回复无需 API Key，也无需本地安装包。AI 写作、回复判断、联网搜索与配图需配置对应服务，可能产生第三方费用。本机 Codex 生图是可选高级功能，需要兼容的乔木本地助手及账号；普通写作和云端配图不依赖它。

数据默认保存在本浏览器，不参与 Chrome Sync。你发起 AI 或搜索操作时，相关内容会发送至你配置的服务。扩展不自动发帖、不自动关注，不读取私信或 Chrome 浏览历史。完整数据说明、兼容要求与帮助见项目主页及隐私政策。
