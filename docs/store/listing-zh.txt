乔木 X 助手，让你在 X 上读得清楚，聊得顺手。

用可撤销的回复折叠减少干扰，用常用 @ 找到想聊的人，再把值得保留的书签带走。界面为简体中文。

整理回复
• 接入 TypeSafe Jev，显示回复的 AI 生成可能性；可设置自动折叠阈值，随时展开。
• 用机器人 / 真人按钮人工标注，记录可在后台查看和删除。后续判断可参考少量相关标注样本。
• 支持本机保留与屏蔽名单。不会自动拉黑；X 上的拉黑仍需你在原生界面确认。
• 短回复不会仅因字数少而被判为低质量。

让互动更顺手
• 常用 @ 支持昵称、账号、备注、全拼和拼音首字母搜索。
• 选择联系人后，在光标处插入「昵称 @账号」，不会自动发送。
• 确认回复发送成功后才记录回复对象，也可手动添加、置顶、编辑或移除。
• 预置作者 @vista8，方便反馈问题，可随时移除。

记录你的看好
• 符合数据条件的主帖显示火焰图标与热帖概率估计，目标浏览量可设置。
• 点击「我感觉能爆」保存当时判断，后续再次看到帖子时更新可见互动数据。
• 原始预测与后续观测分别保留；没有后台持续抓取或到期自动补齐。

把书签留在自己手里
• 打开 X 书签页，自动保存已加载的书签；顶部进度可随时暂停，暂停选择会被记住。
• 搜索、添加备注与标签，导出 Markdown。书签与联系人按 X 账号分开保存在本机。
• 只保存浏览时已加载的内容，不保证一次导出全部历史收藏。

开始使用
安装后刷新 X。书签整理、联系人、人工标注可直接使用，无需模型密钥。AI 判断与热帖预测需在「连接」中填写你自己的 Jev API Key；支持乔木 Magpie、TypeSafe、OpenRouter、Vercel AI Gateway 及兼容决策接口的自定义服务。模型服务可能收费，费用由所选服务商收取；本扩展免费提供。

你的数据
配置、密钥、标注、联系人和书签保存在此浏览器，不使用 Chrome Sync。启用模型功能后，判断所需的帖子文字、上下文、可见互动数据及少量人工样本会发送给你选择的模型服务；不会发送 X Cookie 或私信。模型服务访问权限仅在你连接相应服务时申请。没有广告追踪或独立遥测。

AI 概率和热帖概率都是模型估计，可能误判，不能证明作者身份或保证传播结果。人工标注只作为后续判断参考，不会重新训练模型。乔木 X 助手是独立开源项目，与 X 官方无隶属关系。
