# 设置菜单重新规划 · 2026-10-20

读取为：Chrome 扩展的 400px 弹窗 + 完整设置页，面向 X 重度中文读者，用 DESIGN.md 已定的 Vercel 黑白语言，倾向「安静的系统设置」。
视觉语言已锁定（黑白、系统中文字体、细分隔线、无侧边色条），四个方向的差异在**信息架构、导航结构和交互方式**，不在配色。

功能契约：
- 3 秒内：知道自动隐藏开着没有、今天隐藏了多少、AI 判断能不能用（是否已连接模型）。
- 必须能做：一键暂停；调宽松/严格；关掉引流识别；把误判的人加进「始终显示」；连接模型。
- 其余（书签、待回复、常用 @、热帖、搜索、兴趣、账号评分）是补充体验：可以找到，但不抢核心。

主要问题：

1. 核心「隐藏」只是 8 个入口中的一个；弹窗第一屏是统计数字和演示条，热帖预测开关比引流开关更显眼（引流开关根本没有）。
2. 同一件事散在几处：热帖开关在概览、目标在过滤；看好记录在隐藏页和「工作台 → 复盘」两处；「我的 X 账号」选择器出现 4 次。
3. 「账号」里混着常用 @（发帖工具）和标注统计（判断记录），两件事无关。
4. 阈值有单选、数字框、滑块三种控件；同一页面有的开关即时生效、有的要点「保存设置」。
5. 技术词进入主流程：复用结果、决策接口、Noul 概率、Base URL。
6. 实现隐患：`normalizeSettings`（src/core.js）只保留白名单字段，`spamGuard` 目前写入后会被丢弃；要先在 core.js 白名单加上，设置页开关才能生效。

结论：

- 成熟插件都把**核心开关放在弹窗第一屏**，次要功能进完整设置页、按用途分组。
- 「例外」是过滤类插件的标配，且默认就排除我关注的人和关注我的人——误伤熟人是最伤信任的事。
- 引流识别适合「本机规则 + 可订阅名单 + 可申诉」，不依赖模型。
- 低使用率功能收起，不要和核心并列。
- 不学：按认证蓝标一刀切隐藏（违反「认证不能独立判定」）、自动屏蔽/拉黑（违反 AGENTS.md）、跳过 X 确认的快速拉黑。

## 3. 新的信息架构（推荐 B；四个方向共享这套取舍）

定位（2026-10-20 用户补充）：目标是「X 必装插件」，有效改善 X 使用体验。核心仍是**安静的回复区**（自动隐藏 AI 与引流回复），其余功能按「在 X 上要做的事」分组，每组都能继续加功能而不挤到首屏。

### 全部现有功能的归属

| 分组 | 功能（X 页面里的入口） | 设置里的位置 | 默认 |
|---|---|---|---|
| **回复区**（核心，首屏） | 自动隐藏 AI 回复（互动栏判断按钮 + 隐藏一行） | 开关 + 敏感度三档 | 开 · 标准 |
| | 引流回复识别 `spamGuard`（本机规则） | 开关 | 开 |
| | 重复回复 | 开关 | 开 |
| | 例外：我关注的、关注我的（新）、始终显示、本机屏蔽 | 子页 | 前两项开 |
| | 高级：自定义百分比、只标注不隐藏、附加规则、词汇规则、不可见方向符 | 折叠 | — |
| | 标出值得一读 | 开关 | 新装关 |
| **功能**（每项：开关 + 子页） | 稍后回复（互动栏按钮、提及收集） | 子页：队列、提及收集开关 | 开 |
| | 常用 @（编辑器 @ 按钮、自动记下回复对象） | 子页：联系人 | 开 |
| | 书签保存与导出（书签页吸顶条） | 子页：列表、导出 | 开 |
| | 作者信息（关注数、关注关系徽章） | 开关 | 开 |
| | 热帖预测（时间旁火焰）+ 目标浏览量 | 子页 | 新装关 |
| | 看好追踪（合并原「复盘」） | 子页 | 跟随热帖 |
| | 高级搜索 + 已存搜索 | 子页 | — |
| | 兴趣估计（兴趣按钮）+ 想多看/少看 | 子页 | 关 |
| | 账号评分（主页「分析值得关注」） | 开关 + 说明 | 开 |
| **X 体验**（新组，见第 4 节） | 时间线、界面精简等 | 每项一个开关 | 全关 |
| **我的记录** | 标注、账号统计、最近操作、社区共建 | 子页 | 社区关 |
| **模型与数据** | 连接、每日上限、试一条回复、数据去向、清空数据 | 子页 | 上限 10,000 |

原则：在 X 页面上加的**每个按钮都在设置里有自己的开关**（现在稍后回复、作者信息、账号评分、@ 按钮都关不掉）。「我的 X 账号」只在「功能」组顶部出现一次。

### 弹窗

1. 总开关「自动隐藏」+ 「今天隐藏 23 条 · AI 17 · 引流 6」。未连接模型时：「引流识别已开启；AI 判断需要连接模型 → 去连接」。
2. 两个核心开关：隐藏 AI 回复（显示当前档位）、隐藏引流回复。
3. 最近隐藏 3 条，可「显示」或「始终显示此人」。
4. 「设置 ›」。

删掉：复用结果数字、演示折叠条、热帖开关、看好追踪按钮。

### 交互规则

- 开关、分段改了就存，toast「已保存」；只有文本类（附加规则、词汇、密钥、兴趣）保留保存按钮。去掉「保存设置」「保存每日上限」。
- 子页有返回「‹ 设置」，地址写进 hash（`#features/inbox`），刷新后回到原处。
- 主流程不出现：复用结果、Noul、决策接口、Base URL。

### 合并与删除

| 现状 | 处理 |
|---|---|
| 概览 + 过滤 | 合并为「回复区」 |
| 账号（常用 @ + 标注统计） | 拆开：常用 @ → 功能；统计 → 我的记录 |
| 工作台 5 子页 + 书签 + 看好追踪 | 解散为「功能」组里的独立子页 |
| 「复盘」与「看好追踪」 | 合并为一个 |
| 阈值：单选 + 数字 + 滑块 | 三档分段，自定义百分比进高级 |
| 「只显示结果」模式 | 降为高级「只标注，不隐藏」 |
| 关于 + 页脚反馈 | 合并到页脚，关于作者折叠 |
| 复用结果数字、演示条 | 删除 |
