让插件长在 X 里，而不是贴在 X 上

方向样机，不是最终插件。只比较「关注数 / 待回复 / AI 估计 / 兴趣 / 隐藏与拉黑」放在哪里；字号、颜色、图标尺寸都按 X 原生值复刻。

对照用，不可选

为什么看起来「贴上去的」

  1. 作者行塞了 4 样东西：关注数、关系、待回复、兴趣，全挤在时间后面，和名字抢视线；X 自己的作者行只有名字 · 账号 · 时间。
  2. 每条回复多出一整行（隐藏 / 拉黑 / 展开），约 +36px，像第二条互动栏，打断 X 的节奏。
  3. 字号颜色不是 X 的：插件用 11–12px、#666；X 用 13/15px、#536471。小一号就显得是外挂。
  4. AI 标签红色胶囊、两行换行（「AI 86 / 仅标记」），比点赞数还抢眼。
  5. 待回复图标离 X 的收藏很远，语义相近却不在一起。

四个方向的差异在「位置」而不在配色：插件必须复用 X 的字体与颜色，所以这次不做换肤式对比。四个方向底部都加了同一种「自动隐藏」样子：被判断为 AI 的回复不再逐条占位，而是合并成 X 原生风格的一行「已隐藏 N 条…显示」，这是核心状态，各方向共用。也可以混搭，例如「A 的互动栏 + B 的悬停卡片放关注数」，在确认框里写下即可。
